# TrackingStabilizer for AviUtl ExEdit2

## v1.02 更新内容 (小刻みなガクガクの軽減)

補正後の映像が小刻みにガクガクする(特に低フレームレートで書き出すと顕著になる)
現象への対策です。

**原因**: トラッキング解析結果には、フレームごとに数ピクセル程度の細かいノイズ
(検出誤差によるガタつき)が含まれます。60fpsのまま使う分には1フレームの表示
時間が短いため目立ちませんが、低いフレームレートで書き出すと1フレームあたりの
表示時間が伸びるため、同じノイズが何倍も目立って見えてしまいます。

**対策**: 追跡座標を使う前に、前後数フレームぶんの移動平均(簡易ローパス
フィルタ)をかけて、細かいノイズを均してから補正に使うようにしました。

新しいパラメータ「**平滑化(フレーム)**」を追加しました。

- 初期値は 9 (前後4フレームずつ、計9フレームの平均)。
- 値を大きくするほどノイズは減りますが、代わりに素早い本物の手ブレへの
  反応が遅れ、補正がワンテンポ遅れて「ゆらっ」と揺れて見えることがあります。
  ノイズが残る場合は少しずつ大きく、逆に反応が鈍いと感じたら小さくして
  調整してください。
- 1にすると平滑化なし(v1.01までと同じ、生のトラッキング座標をそのまま使用)
  になります。

## v1.01 更新内容 (重要: 安全性の修正)

v1.00で、「追跡レイヤー」に図形以外のオブジェクト(音声ファイル、空、テキストの
みなど)を指定するとAviUtl2がクラッシュし、プロジェクトの編集が出来なくなる
不具合がありました。v1.01では以下を修正しています。

- 追跡レイヤーのオブジェクトが図形(画像)ではない場合、内部処理で発生しうる
  例外(C++例外・アクセス違反などの構造化例外)を `__try/__except` (SEH) で
  必ず捕捉するようにし、アプリごと落ちることが無いようにしました。
- 座標が取得できない場合は「補正をスキップ」して処理を継続するようにしました
  (映像自体は普通に再生・書き出しされ、ブレ補正だけが効かない状態になります)。
- 取得できなかった場合、AviUtl2のログにその旨を警告として出力するようにしました
  (`InitializeLogger` に対応。連続スパムしないよう、状態が変わるまでは1回だけ
  出力します)。
- 同梱していたSDKヘッダー(`filter2.h`/`plugin2.h`)がShift-JISのままだった
  ため発生していた `warning C4828` (文字コード不一致の警告) を解消するため、
  ヘッダーをUTF-8に変換して同梱し直しました。動作には影響のない警告でしたが、
  気持ち悪いので直しました。

**必ずこのフォルダの中身一式で再ビルドしてください**(`TrackingStabilizer.cpp`・
`CMakeLists.txt`・`aviutl2_sdk/*.h` を古いものと混在させないでください)。


モーショントラッキングプラグイン(例: MotionTracking MK-II Plus for AviUtl2)が
出力した「追跡点を表す図形オブジェクト」の座標を毎フレーム読み取り、基準フレーム
からの移動量(=手ブレ量)の符号を反転して映像へ加算することで、手ブレ補正を行う
フィルタ効果プラグインです。

自作の画像処理は行わず、AviUtl ExEdit2 本体が持つ「オブジェクトの座標を参照する
API (get_output_image_param)」と「対象オブジェクトへの相対オフセット (obj.ox /
obj.oy 相当)」だけを使って補正しているため、処理は軽量です。

## 仕組み

1. 指定した「追跡レイヤー」上にある図形オブジェクト(トラッキングプラグインが
   打ったマーカー)の、**現在フレームの座標**と**基準フレームの座標**を取得する。
2. その差分 `(dx, dy)` が「基準フレームから今フレームまでにブレた量」。
3. `-dx, -dy` を映像オブジェクトの座標に加算することで、ブレを打ち消す。

トラッキングプラグイン側の「Invert Position(反転)」はOFFのまま使う想定です
(素直にブレと同じ方向に動く図形を作らせて、本プラグイン側で符号反転します)。
「部分フィルタとして挿入」もOFFにしてください。部分フィルタはエフェクトのみで
「画像オブジェクト」ではないため、本プラグインから座標を読み取れません。
必ず「図形+標準描画」として挿入される通常モードを使ってください。

## ビルド方法 (Windows / Visual Studio が必要です)

このプラグインは AviUtl ExEdit2 本体に読み込まれる Windows DLL (.auf2) なので、
**Windows 上で Visual Studio (MSVC) を使ってビルドする必要があります。**
Claude 側の環境は Linux のためここではビルドできず、ソース一式のみ用意しています。

### 必要なもの
- Windows 10/11
- Visual Studio 2022 (「C++によるデスクトップ開発」ワークロード)
- CMake 3.20 以上 (Visual Studio に同梱のものでも可)

### 手順

1. このフォルダ一式 (`TrackingStabilizer.cpp`, `CMakeLists.txt`,
   `aviutl2_sdk/filter2.h`, `aviutl2_sdk/plugin2.h`) を1つのフォルダに置く。
2. 「x64 Native Tools Command Prompt for VS 2022」を開き、フォルダに移動。
3. 以下を実行してビルドする。

   ```bat
   cmake -B build -A x64
   cmake --build build --config Release
   ```

4. `build\Release\TrackingStabilizer.auf2` が生成されます。

   もし Visual Studio でGUIから作業したい場合は、`cmake -B build -A x64` の後に
   生成された `build\TrackingStabilizer.sln` を Visual Studio で開いて
   「Release」構成でビルドしてもOKです。

### インストール

生成された `TrackingStabilizer.auf2` を、AviUtl ExEdit2 のプレビュー画面へ
ドラッグ&ドロップするとプラグインフォルダへ自動インストールされます
(SDK付属の `aviutl2_plugin_sdk.txt` に記載の方法と同じです)。

## 使い方

1. **モーショントラッキングプラグインで追跡用の図形を作る**
   - 補正の基準にしたい画面内の特徴点(動かない壁の角、看板の文字など)を選択し、
     解析(トラッキング)を実行。
   - 「部分フィルタとして挿入」はOFF、「Invert Position」もOFFのまま
     「Insert Object」を押し、追跡結果の図形オブジェクトをレイヤーに挿入する。
   - このレイヤーは映像本体とは別のレイヤーにしておく(結果確認がしやすいよう、
     図形は後で非表示にしてもOKです)。

2. **補正したい映像オブジェクトに本プラグインを追加**
   - 映像オブジェクトを選択し、フィルタ効果の追加から「手ブレ補正」を選択。

3. **設定項目を調整**
   - `追跡レイヤー` : 手順1で図形を挿入したレイヤー番号(タイムライン表示の番号)。
   - `基準フレーム` : ブレが無いとみなす基準フレーム(通常は映像の先頭フレーム)。
   - `補正強度(%)` : 100%で移動量をそのまま打ち消す。効きすぎ/物足りない場合に
     調整。
   - `平滑化(フレーム)` : トラッキングの細かいノイズを均す移動平均の幅。
     小刻みなガクガクが残る場合はここを大きくする(初期値9)。
   - `X軸を補正する` / `Y軸を補正する` : 必要な軸だけ補正したい場合にOFFにする。
   - `移動量を反転して適用する` : 通常はON。トラッキング側で
     「Invert Position」を有効にして挿入した場合はOFFにしてください
     (すでに反転済みの座標をそのまま加算する動きになります)。

4. プレビューでブレが打ち消されているか確認し、`補正強度` や `基準フレーム` を
   微調整してください。

## 制限事項・注意点

- 平行移動(X/Y)のみを補正します。回転や拡大縮小によるブレの補正はしていません
  (`OBJECT_IMAGE_PARAM` には rx/ry/rz, sx/sy/sz もあるため、必要であれば同様の
  仕組みで拡張可能です)。
- 追跡レイヤーの図形オブジェクトが「基準フレーム」の時間に存在しない(その区間に
  トラッキング結果が無い)場合、その基準座標の取得に失敗し、現在フレームの座標を
  仮の基準として使うため補正がかからなくなります。基準フレームは、追跡結果の
  図形オブジェクトが存在する範囲内のフレームを指定してください。
- 手ブレ補正のぶん映像端に隙間が出ることがあります。必要に応じて「リサイズ」
  フィルタ等で少し拡大してごまかす、または「フィルタ効果」として映像より広い
  作業領域を持つオブジェクトに適用してください。
